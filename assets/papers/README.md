# Author PDFs

Drop accepted-manuscript ("author version") PDFs here and link them from
`index.html` with a `PDF` entry in that paper's `<p class="pub-links">`:

```html
<a href="assets/papers/chase2025.pdf">PDF</a>
```

Currently hosted here: none — the JSS and CHASE papers link to arXiv instead,
and Future Internet is open access at MDPI.

Still needing an author PDF: PROFES 2024 (ReqGenie), PCI '23, ICEGOV '22.

## Self-archiving policies

- **ACM** (PCI, ICEGOV) — authors may post the accepted version on a personal
  site. Check the specific rights form you signed.
- **Springer** (PROFES) — accepted manuscript allowed on a personal site,
  usually after a 12-month embargo, with a link to the published version.
- **IEEE** (CHASE) — accepted version allowed on a personal site with the
  required copyright notice.
- **Elsevier** (JSS) — accepted manuscript allowed on a personal site
  immediately, under CC BY-NC-ND.

Verify against each publisher's current policy before posting.
